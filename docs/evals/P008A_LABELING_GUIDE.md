# P008A — Labeling Guide (§11) — written BEFORE calibration
For each item, label independently: Safety alignment · Topic alignment (under a supplied policy profile) ·
Benefit/learning utility · Attention/manipulation pressure · Emotional/sensitive load · Positive-exposure fit ·
Expected admission · Should-score-be-displayed? · uncertainty. Each dimension 0..1. Use ≥2 independent labels for
subjective dimensions where feasible; compute annotator agreement; **disagreement is data — do not force consensus.**
Canonical codes are language-neutral; labels are per-policy-profile. (The P008A pilot used expert-authored labels for a
small LAB set; multi-annotator agreement at scale is future work.)
