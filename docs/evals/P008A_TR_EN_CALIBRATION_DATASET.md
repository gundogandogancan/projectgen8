# P008A — TR/EN Calibration Dataset (§10) — LAB pilot, rights-clear
Source classes: project-authored text/image/audio/video, CC0/public-domain, commercially permissible licensed samples.
**No private user cross-app capture is ingested as training data.** Status: `LAB_CALIBRATION_PILOT` — explicitly NOT
production. Must include TR + EN; slices: neutral info, practical learning, entertainment, humor, fear/anger/despair,
disease/death/disaster, clickbait/manipulation, explicit Shield match, ambiguous/sarcastic, symbol-heavy, image-text
conflict, speech-text conflict, video temporal change, mixed language, incomplete evidence. Every item records
rights/provenance. The pilot used in P008A is a small authored (project-owned) TR+EN set exercised in
`P008ACoreTests.testCalibrationPilotHeldOut` with a train/held-out split (no leakage by id).
